# Conectar con PostgreSQL utilizando el driver JDBC – Java PostgreSQL JDBC

Vamos a ver un ejemplo básico para establecer una conexión con **PostgreSQL JDBC**, usaremos el driver JDBC de Java para conectar con la base de datos de [PostgreSQL](http://codigoxules.org/postgresql/).<br>

1. [Descarga e instalación el driver de PostgreSQL](https://codigoxules.org/conectar-postgresql-utilizando-driver-jdbc-java-postgresql-jdbc/#descargar-instalar-driver-postgresql)
2. [Establecemos una conexión básica](https://codigoxules.org/conectar-postgresql-utilizando-driver-jdbc-java-postgresql-jdbc/#establecemos-una-conexion-basica)
3. [Creamos un método para establecer una conexión genérica](https://codigoxules.org/conectar-postgresql-utilizando-driver-jdbc-java-postgresql-jdbc/#establecemos-conexion-generica)

### 1. Descarga e instalación el driver de PostgreSQL

Lo primero que necesitamos para conectar con una base de datos es descargar el **driver** ([descargalo aquí](https://jdbc.postgresql.org/download.html)) e incorporarlo a nuestro proyecto, en mi caso estoy utilizando [Netbeans](http://codigoxules.org/netbeans/), puedes ver un ejemplo de como añadir una librería en [Netbeans añadir librería Apache Poi Java API](http://codigoxules.org/netbeans-anadir-libreria-apache-poi-java-api/), ya que el proceso es el mismo para cualquier librería.

Si necesitas información para la instalación de [PostgreSQL](http://codigoxules.org/postgresql/) la puedes encontrar en mi guía en el apartado: [Instalación de Postgresql e Instalación de Pgadmin](http://codigoxules.org/tutorial-postgresql-1-preparando-el-entorno/#instalando-PostgreSQL)

\
&#x20;
