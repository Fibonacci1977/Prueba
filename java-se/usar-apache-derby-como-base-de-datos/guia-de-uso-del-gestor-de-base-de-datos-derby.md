| <p><br></p><p>En esta página encontraréis información sobre el uso del gestor de base de datos proporcionado con el Servidor de aplicaciones de Sun 8.2, denominado Derby. En sus versiones anteriores, 8.0 y 8.1, este servidor proporcionaba un gestor diferente, denominado PointBase. Derby se utilizará como gestor de base de datos en las prácticas relacionadas con la creación de EJB de Entidad.</p><p>Esta guía contiene la información necesaria para configurar vuestra base de datos: comandos de gestión, ejecución de sentencias SQL, y opciones de configuración.</p><p>.</p> |

|  Ejecución de sentencias SQL: `ij` | <img src="http://www.it.uc3m.es/imag/degradtabla2.jpg" alt="" data-size="original"> |
| ---------------------------------- | ----------------------------------------------------------------------------------- |

| <p><br></p><p>Derby proporciona una consola para introducir sentencias SQL. Para lanzar dicha consola es necesario realizar los siguientes pasos:</p><ol><li><p>Añadir a la variable de entorno <code>CLASSPATH</code>, <code>${J2EE_HOME}/derby/lib/derbyclient.jar</code> y <code>${J2EE_HOME}/derby/lib/derbytools.jar</code>.</p><ul><li>Cambiar la variable  <code>DERBY_INSTALL</code>, inicializaciándola a <code>${J2EE_HOME}/derby/</code></li></ul></li><li><p>En el directorio <code>${J2EE_HOME}/derby/frameworks/NetworkServer/bin</code> ejecutar:</p><pre><code>   $ bash ./ij.ksh
	 
</code></pre><p>La línea que ejecuta este script es la siguiente:</p><pre><code>   java -Dij.driver=org.apache.derby.jdbc.ClientDriver -Dij.protocol=jdbc:derby://localhost:1527/ 
	       -Dij.user=APP -Dij.password=APP org.apache.derby.tools.ij
	  
</code></pre><p>Esta línea nos indica el "driver", la URL del gestor de base de datos, y el usuario con su respectivo "password". Por defecto, el usuario y su contraseña son <code>app</code>.</p></li><li><p>Conectarse a la base de datos sobre la que se quiere trabajar para poder ejecutar sentencias SQL. Para ello, ejecutar:</p><pre><code>    ij> connect 'jdbc:derby://localhost:1527/sun-appserv-samples;create=true;';
	  
</code></pre><p>Esta sentencia permite conectarse con la base de datos configurada por defecto en el gestor, <code>sun-appserv-samples</code>.</p></li><li><p>Ahora es posible ejecutar sentencias SQL individuales o cargar un fichero con varias sentencias para ejecutarlo en su totalidad:</p><ul><li>Para ejecutar sentencias SQL individuales, escribir la sentencia a continuación del indicador <code>ij></code> y terminar con ";".</li><li><p>Para ejecutar sentencias SQL almacenadas en un fichero, ejecutar:</p><pre><code>  ij> run 'myscript.sql';
		
</code></pre></li></ul></li><li><p>La información necesaria para arrancar la herramienta <code>ij</code> puede ser visualizada en la herramienta de administración, así:</p><ul><li>En el navegador, entrar a http://localhost:4848. Introducir el "login" y "password" de administrador.</li><li>En el árbol de <code>Resources</code>, extender <code>JDBC</code> y a continuación seleccionar <code>Connection Pool</code>.</li><li>En la ventana de la derecha, clic en <code>DerbyPool</code>. En el apartado <code>Properties</code> podéis encontrar información sobre el puerto, nombre del servidor, nombre de la base de datos, usuario, "password", etc.</li></ul></li></ol><p><br></p> |

<table data-header-hidden><thead><tr><th></th></tr></thead><tbody><tr><td><p><br></p><p>Para facilitar la realización de las prácticas del EJB de entidad cuya persistencia está gestionada por el bean, vamos a crear un usuario específico (swc/swc). El esquema ("schema") corresponde al nombre de usuario, y se puede crear implicita o explicitamente. De forma implicita, se crea cuando se crea un objeto en la base de datos (por ejemplo, una tabla). Se crea explicitamente ejecutando:</p><pre><code>  ij>create schema nombre_schema;
  
</code></pre><ol><li><p>Abrir la herramienta de administración y crear un nuevo <code>Connection Pool</code>. Para ello debemos realizar los siguientes pasos:</p><ol><li>En el árbol de <code>Resources</code>, extender <code>JDBC</code> y a continuación seleccionar <code>Connection Pool</code>.</li><li>En la parte derecha de la página, clic en el botón <code>New...</code> para crear un nuevo recurso:</li></ol></li><li>Arrancar el gestor si no lo habéis arrancado previamente.</li><li><p>Arrancaar la herramienta <code>ij</code> y ejecutar:</p><pre><code>   ij> connect 'jdbc:derby://localhost:1527/bankdb;create=true;user=swc;password=swc;';
   
</code></pre></li><li>Crear la tabla de usuarios en la base de datos, <code>users</code>, con el script <a href="https://www.it.uc3m.es/labswc/practicas/j2ee/source/create_table.sql">create_table.sql</a>. Automáticamente se crea el "schema" <code>SWC</code>.</li></ol></td></tr></tbody></table>
