# Configuración de la fuente de datos en JBoss Wildfly (con MySQL)

Para aquellos que estaban deseosos de probar el nuevo servidor de aplicaciones JBoss, Wildfly, y que acabaron encontrando dificultades al crear una aplicación de acceso a la base de datos, aquí tienen un breve tutorial que muestra cómo configurar su fuente de datos para MySQL.

1\. Acceda al directorio _**$WILDFLY\_HOME/modules/system/layers/base/com**_ .\
2\. Una vez allí, cree el directorio _**mysql**_ y su subdirectorio _**main**_ .\
3\. Dentro de _**main**_ , coloque el **archivo JAR** del controlador JDBC para MySQL.\
4\. Ahora cree un archivo llamado _**module.xml**_ y agregue las siguientes líneas de código:

|   | `<?xml` `version="1.0"` `encoding="UTF-8"?>` `<module` `xmlns="urn:jboss:module:1.1"` `name="com.mysql">    <resources>        <!-- Dentro de "path" coloque o nome completo do seu jar -->        <!-- Nota: Não se esqueça de colocar '.jar' no final do nome, assim como no exemplo abaixo -->        <resource-root` `path="mysql-connector-java-5.1.26-bin.jar"/>    </resources>    <dependencies>        <module` `name="javax.api"/>        <module` `name="javax.transaction.api"/>        <module` `name="javax.servlet.api"` `optional="true"/>    </dependencies></module>` |
| - | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

5 – Ahora accede al directorio _**$WILDFLY\_HOME/standalone/configuration**_ y abre el archivo _**standalone.xml**_ .\
6 – Busca la etiqueta _**datasource**_ . Encontrarás una fuente de datos preconfigurada para la base de datos H2. Debajo, crea tu propia fuente de datos siguiendo el ejemplo a continuación:

|   | `<!-- Tenho um projeto chamado livraria, isso explica os nomes abaixo, mas você poderia colocar qualquer outro nome. --><datasource` `jta="true"` `jndi-name="java:jboss/datasources/livraria-ds"` `pool-name="livraria"` `enabled="true"` `use-java-context="true"` `use-ccm="true">    <!-- Aqui você deve colocar o endereço da sua base de dados -->    <connection-url>jdbc:mysql://localhost:3306/livraria</connection-url>    <driver>mysql</driver>    <transaction-isolation>TRANSACTION_READ_COMMITTED</transaction-isolation>    <pool>        <min-pool-size>10</min-pool-size>        <max-pool-size>100</max-pool-size>        <prefill>true</prefill>    </pool>    <security>        <user-name>root</user-name>        <password>root</password>    </security>    <statement>        <prepared-statement-cache-size>32</prepared-statement-cache-size>        <share-prepared-statements>true</share-prepared-statements>    </statement></datasource>` |
| - | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

7 – Justo debajo de tu _**fuente de datos**_ deberías encontrar una etiqueta llamada _**drivers**_ ; dentro de ella copia y pega el siguiente código:

|   | `<driver` `name="mysql"` `module="com.mysql">    <xa-datasource-class>com.mysql.jdbc.jdbc2.optional.MysqlXADataSource</xa-datasource-class></driver>` |
| - | ----------------------------------------------------------------------------------------------------------------------------------------------------- |

8 – También debes realizar algunos cambios en _**el archivo persistence.xml**_ de tu proyecto . Sigue el ejemplo a continuación:

|   | `<?xml` `version="1.0"` `encoding="UTF-8"?><persistence` `xmlns="`[`http://java.sun.com/xml/ns/persistence`](http://java.sun.com/xml/ns/persistence)`"    xmlns:xsi="`[`http://www.w3.org/2001/XMLSchema-instance`](http://www.w3.org/2001/XMLSchema-instance)`"    xsi:schemaLocation="`[`http://java.sun.com/xml/ns/persistence`](http://java.sun.com/xml/ns/persistence) [`http://java.sun.com/xml/ns/persistence/persistence_2_0.xsd`](http://java.sun.com/xml/ns/persistence/persistence_2_0.xsd)`"    version="2.0">` `<persistence-unit` `name="livraria"` `transaction-type="RESOURCE_LOCAL">` `<!-- Ao invés de utilizar o seguinte provider, como de costume: -->        <!-- <provider>org.hibernate.ejb.HibernatePersistence</provider> -->        <!-- Vamos usar o provider abaixo: -->        <provider>org.hibernate.jpa.HibernatePersistenceProvider</provider>` `<!-- Não se esqueça de informar ao persistence.xml qual datasource você estará usando, para isso siga o exemplo abaixo: -->        <jta-data-source>java:jboss/datasources/livraria-ds</jta-data-source>        <!-- Obs.: Caso seja necessário você rodar uma classe main para popular o banco de dados, remova a tag acima. -->` `<class>com.lucas.livraria.model.Livro</class>` `<properties>            <!-- Uma vez que você está usando datasource não é necessário configurar novamente o acesso ao banco -->            <!-- Coloquei aqui apenas como um exemplo -->            <property` `name="javax.persistence.jdbc.driver"` `value="com.mysql.jdbc.Driver"` `/>            <property` `name="javax.persistence.jdbc.url"` `value="jdbc:mysql://localhost/livraria"` `/>            <property` `name="javax.persistence.jdbc.user"` `value="root"` `/>            <property` `name="javax.persistence.jdbc.password"` `value="root"` `/>` `<property` `name="javax.persistence.validation.mode"` `value="none"` `/>` `<property` `name="hibernate.hbm2ddl.auto"` `value="update"` `/>            <property` `name="hibernate.show_sql"` `value="true"` `/>            <property` `name="hibernate.dialect"` `value="org.hibernate.dialect.MySQL5InnoDBDialect"` `/>        </properties>    </persistence-unit></persistence>` |
| - |
